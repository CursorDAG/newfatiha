═══════════════════════════════════════════════════════════════

Выполните команды ПОСТРОЧНО на сервере:

──────────────────────────────────────────────────────────────
Команда 1: Выдать права на таблицы
──────────────────────────────────────────────────────────────

sudo -u postgres psql -d fatiha -c "GRANT ALL PRIVILEGES ON TABLE \"PageContent\" TO fatiha_user;"


──────────────────────────────────────────────────────────────
Команда 2: Выдать права на остальные новые таблицы
──────────────────────────────────────────────────────────────

sudo -u postgres psql -d fatiha -c "GRANT ALL PRIVILEGES ON TABLE \"Broadcast\", \"TeacherProfile\", \"EnrollmentRequest\", \"NotificationPreference\" TO fatiha_user;"


──────────────────────────────────────────────────────────────
Команда 3: Выдать права на все таблицы сразу
──────────────────────────────────────────────────────────────

sudo -u postgres psql -d fatiha -c "GRANT ALL PRIVILEGES ON ALL TABLES IN SCHEMA public TO fatiha_user;"


──────────────────────────────────────────────────────────────
Команда 4: Проверить что права выданы
──────────────────────────────────────────────────────────────

sudo -u postgres psql -d fatiha -c "SELECT grantee, privilege_type FROM information_schema.role_table_grants WHERE table_name='PageContent' AND grantee='fatiha_user';"


──────────────────────────────────────────────────────────────
Команда 5: Перезапустить приложение
──────────────────────────────────────────────────────────────

pm2 restart fatiha


──────────────────────────────────────────────────────────────
Команда 6: Проверить логи
──────────────────────────────────────────────────────────────

pm2 logs fatiha --lines 20
