## Координация команды

### Инструменты коммуникации
- **TaskList** - отслеживание прогресса всех задач
- **SendMessage** - коммуникация между агентами
- **TaskUpdate** - обновление статуса задач

### Правила работы
1. Каждый агент работает в plan mode - сначала план, потом реализация
2. Team Lead одобряет планы перед началом реализации
3. Агенты сообщают о завершении задач через TaskUpdate
4. При блокерах - немедленно сообщать Team Lead
5. Следовать всем правилам из CLAUDE.md

### Последовательность запуска

**Шаг 1:** Team Lead создает команду и задачи
```
TeamCreate → TaskCreate для всех задач
```

**Шаг 2:** Запустить db-architect
```
Agent(name: "db-architect", prompt: "см. STAGE1_AGENT_DB_ARCHITECT.md")
```

**Шаг 3:** После завершения db-architect → запустить параллельно 4 агента
```
Agent(name: "admin-developer", ...)
Agent(name: "moderator-developer", ...)
Agent(name: "email-specialist", ...)
Agent(name: "gender-implementer", ...)
```

**Шаг 4:** Параллельно с Шагом 3 → запустить chat-developer
```
Agent(name: "chat-developer", ...)
```

**Шаг 5:** Team Lead проводит интеграционное тестирование
