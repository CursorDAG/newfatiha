## Следующие действия

**Перед запуском команды:**
1. Исправить TypeScript ошибки в текущем коде
2. Закоммитить систему уведомлений
3. Убедиться что все тесты проходят
4. Проверить что БД в актуальном состоянии

**Запуск команды:**
1. `TeamCreate(team_name: "stage1-team")`
2. Создать задачи через TaskCreate для каждого агента
3. Запустить db-architect (первым)
4. После завершения db-architect → запустить остальных параллельно
5. Мониторить прогресс через TaskList
6. Координировать через SendMessage

**После завершения Этапа 1:**
- Проверить все критерии завершения
- Создать аналогичные инструкции для Этапа 2
- Перейти к ROADMAP_PART2.md
