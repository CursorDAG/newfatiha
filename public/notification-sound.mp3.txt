# Notification Sound File

This file should be a short MP3 audio file (1-2 seconds) for notification alerts.

You can:
1. Download a free notification sound from sites like freesound.org or zapsplat.com
2. Use a simple beep or chime sound
3. Keep the file size small (< 50KB recommended)

Place the audio file at: /public/notification-sound.mp3

If the file is missing, the NotificationBell component will handle it gracefully and disable sound notifications.
