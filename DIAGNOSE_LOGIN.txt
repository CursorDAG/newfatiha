Выполните на сервере эти команды для диагностики:

──────────────────────────────────────────────────────────────
1. Проверить структуру таблицы User (есть ли поле status?)
──────────────────────────────────────────────────────────────

sudo -u postgres psql -d fatiha -c "\d \"User\"" | grep -E "status|emailVerified|verificationToken"


──────────────────────────────────────────────────────────────
2. Проверить что администратор создан
──────────────────────────────────────────────────────────────

sudo -u postgres psql -d fatiha -c "SELECT email, name, role, status, \"emailVerified\" FROM \"User\" WHERE email = 'admin@fatiha.ru';"


──────────────────────────────────────────────────────────────
3. Проверить логи приложения (ошибки при входе)
──────────────────────────────────────────────────────────────

pm2 logs fatiha --lines 50 --err


──────────────────────────────────────────────────────────────
4. Проверить статус миграций
──────────────────────────────────────────────────────────────

cd /var/www/newfatiha
npx prisma migrate status
