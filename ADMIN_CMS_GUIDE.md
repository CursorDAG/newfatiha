# Руководство по CMS и массовым рассылкам

## Обзор

Реализована система управления контентом (CMS) для главной страницы и система массовых рассылок для администраторов.

## Новые возможности

### 1. CMS для главной страницы

**Путь:** `/admin/cms`

**Функционал:**
- Редактирование Hero Section (заголовок, подзаголовок, кнопки)
- Редактирование секции "О платформе"
- Предпросмотр изменений
- Сохранение контента в базу данных
- Fallback на статический контент если CMS не настроен

**API:**
- `GET /api/admin/cms/home` - получить контент
- `PUT /api/admin/cms/home` - обновить контент

**Модель данных:**
```prisma
model PageContent {
  id        String   @id @default(uuid())
  page      String   @unique
  sections  Json
  createdAt DateTime @default(now())
  updatedAt DateTime @updatedAt
}
```

### 2. Система массовых рассылок

**Путь:** `/admin/broadcasts`

**Функционал:**
- Создание рассылок с заголовком и сообщением
- Выбор целевой аудитории:
  - Всем пользователям
  - Только студентам
  - Только учителям
- Установка приоритета (LOW, NORMAL, HIGH, URGENT)
- Опция отправки на email (в разработке)
- История всех рассылок

**API:**
- `POST /api/admin/broadcasts` - создать рассылку
- `GET /api/admin/broadcasts` - получить историю

**Модель данных:**
```prisma
model Broadcast {
  id             String               @id @default(uuid())
  title          String
  message        String               @db.Text
  targetAudience Json
  priority       NotificationPriority @default(NORMAL)
  sendEmail      Boolean              @default(false)
  sentById       String
  sentBy         User                 @relation(fields: [sentById], references: [id])
  sentAt         DateTime             @default(now())
  recipientCount Int                  @default(0)
  readCount      Int                  @default(0)
  createdAt      DateTime             @default(now())
  updatedAt      DateTime             @updatedAt
}
```

### 3. Управление курсами

**Путь:** `/admin/courses`

**Функционал:**
- Просмотр всех курсов всех учителей
- Фильтрация по статусу (опубликованные/черновики)
- Статистика по каждому курсу (потоки, студенты, уроки)
- Общая статистика платформы

**API:**
- `GET /api/admin/courses` - получить все курсы с статистикой

### 4. Обновленная админ-панель

**Компонент:** `AdminLayout`

**Навигация:**
- Dashboard - общая статистика
- Пользователи - управление пользователями
- Заявки учителей - модерация заявок
- Курсы - управление курсами
- CMS - редактор главной страницы
- Рассылки - массовые уведомления
- Настройки - конфигурация системы

**Дизайн:**
- Sidebar с иконками
- Адаптивный layout
- Единый стиль для всех админ-страниц

## Обновления в NotificationService

Расширен метод `broadcast()`:
- Поддержка фильтрации по ролям
- Поддержка приоритета уведомлений
- Поддержка отправки конкретным пользователям
- Логирование статистики

```typescript
await NotificationService.broadcast({
  role: "STUDENT", // или "TEACHER", "ADMIN", undefined для всех
  type: "ANNOUNCEMENT",
  title: "Важное объявление",
  message: "Текст объявления",
  priority: "HIGH",
  sendEmail: true, // опционально
  userIds: ["id1", "id2"], // опционально, для конкретных пользователей
});
```


## Использование

### Редактирование главной страницы

1. Войти как администратор
2. Перейти в `/admin/cms`
3. Отредактировать секции
4. Нажать "Сохранить"
5. Изменения сразу отобразятся на главной странице

### Создание рассылки

1. Войти как администратор
2. Перейти в `/admin/broadcasts`
3. Нажать "Создать рассылку"
4. Заполнить форму:
   - Заголовок (обязательно)
   - Сообщение (обязательно)
   - Целевая аудитория
   - Приоритет
   - Опция email
5. Нажать "Отправить"
6. Уведомления будут доставлены всем выбранным пользователям

### Просмотр курсов

1. Войти как администратор
2. Перейти в `/admin/courses`
3. Использовать фильтры для поиска
4. Просмотреть статистику по каждому курсу

## Безопасность

- Все API endpoints защищены проверкой роли `ADMIN`
- Используется `withErrorHandling` middleware
- Валидация входных данных через Zod (в broadcasts API)
- Проверка сессии через NextAuth
