## Миграция с предыдущих версий

### С версии 1.0.0 на Unreleased

**Требуется:**
1. Применить миграции БД: `npx prisma migrate deploy`
2. Обновить переменные окружения (см. `.env.example`)
3. Запустить seed для тестовых данных: `npx prisma db seed`
4. Перезапустить приложение

**Breaking Changes:**
- Все существующие потоки будут закрыты для записи (`isOpenForEnrollment = false`)
- Все существующие пользователи получат статус `ACTIVE`
- Требуется настройка SMTP для email уведомлений

**Рекомендации:**
- Создайте бэкап БД перед миграцией
- Проверьте работу email уведомлений в staging
- Вручную откройте нужные потоки для записи через админ-панель
