# Email система — настройка и использование

## Изменения

### 1. ✅ Дефолтный email изменён на info@fatiha.ru
**Файл:** `src/lib/email/config.ts`

Все системные письма (регистрация, уведомления) теперь отправляются от `info@fatiha.ru` вместо `noreply@fatiha.ru`.

### 2. ✅ Почтовый клиент в админке
**Страница:** `/admin/mail`

Новый раздел для отправки писем от `admin@fatiha.ru` с возможностью:
- Выбора получателей (все/студенты/учителя/админы/вручную)
- Ввода темы и текста
- Отправки как plain text или HTML
- Просмотра статистики отправки

**API:** `POST /api/admin/mail/send`

## Настройка SMTP

### Вариант 1: Через .env (рекомендуется для продакшена)

Добавьте в `.env`:

```env
# SMTP настройки
SMTP_HOST=smtp.gmail.com
SMTP_PORT=587
SMTP_USER=info@fatiha.ru
SMTP_PASS=your-app-password
SMTP_FROM=info@fatiha.ru
SMTP_FROM_NAME=Fatiha.ru
```

### Вариант 2: Через админ-панель

1. Зайдите в `/admin/settings`
2. Вкладка **Email**
3. Заполните SMTP настройки
4. Сохраните

## Использование почтового клиента

1. Зайдите в `/admin/mail`
2. Выберите получателей:
   - **Все пользователи** — отправка всем
   - **Только студенты** — только с ролью STUDENT
   - **Только учителя** — только с ролью TEACHER
   - **Только администраторы** — только с ролью ADMIN
   - **Указать вручную** — введите email через запятую или с новой строки
3. Введите тему письма
4. Введите текст письма
5. (Опционально) Включите "Отправить как HTML" для HTML-писем
6. Нажмите **Отправить письма**

После отправки вы увидите статистику:
- Всего получателей
- Успешно отправлено
- Ошибок
- Список ошибок (если есть)

## Типы писем

### Системные письма (от info@fatiha.ru)
- Подтверждение email при регистрации
- Уведомления о новых уроках
- Уведомления о проверке ДЗ
- Напоминания о дедлайнах
- Сброс пароля
- Блокировка/разблокировка аккаунта

### Письма от администрации (от admin@fatiha.ru)
- Массовые рассылки
- Объявления
- Новости платформы
- Персональные сообщения

## Безопасность

- Только пользователи с ролью `ADMIN` могут отправлять письма через `/admin/mail`
- Email адреса валидируются через Zod schema
- Ошибки отправки логируются, но не прерывают процесс
- Поддержка как plain text, так и HTML писем

## Troubleshooting

**Письма не отправляются:**
1. Проверьте SMTP настройки в `.env` или админке
2. Проверьте логи сервера на ошибки
3. Для Gmail — используйте App Password, не обычный пароль
4. Проверьте firewall и порты (587 для TLS, 465 для SSL)

**Письма попадают в спам:**
1. Настройте SPF, DKIM, DMARC записи для вашего домена
2. Используйте реальный домен (не @gmail.com) для отправки
3. Прогрейте IP адрес (начните с малых объёмов)

**Ошибка "Invalid login":**
- Gmail: нужен App Password (https://myaccount.google.com/apppasswords)
- Yandex/Mail.ru: разрешите доступ для почтовых клиентов в настройках

## API Reference

### POST /api/admin/mail/send

**Требования:** роль ADMIN

**Body:**
```json
{
  "to": "all" | "students" | "teachers" | "admins" | "custom",
  "customEmails": ["user1@example.com", "user2@example.com"], // только для to="custom"
  "subject": "Тема письма",
  "message": "Текст письма",
  "isHtml": false
}
```

**Response:**
```json
{
  "success": true,
  "results": {
    "total": 100,
    "sent": 98,
    "failed": 2,
    "errors": [
      "user@example.com: Connection timeout",
      "invalid@example.com: Invalid email"
    ]
  }
}
```
