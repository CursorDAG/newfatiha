# PWA Learning System — Полный план реализации

**Версия:** 1.0  
**Дата:** 2026-04-25  
**Статус:** Планирование

## 🎯 Цель проекта

Добавить в PWA Fatiha.ru систему самостоятельного обучения в стиле Duolingo с геймификацией, библиотекой книг и умными уведомлениями о живых уроках с учителями.

## 📋 Основные требования

1. **Не конфликтовать** с текущей системой курсов и учителей
2. **Работать офлайн** — кэширование уроков, прогресса
3. **Push-уведомления** — о живых уроках и стриках
4. **Геймификация** — XP, стрики, лиги, достижения
5. **Библиотека** — публичные книги + материалы от учителей

## ⚠️ Важные принципы

### 1. Изоляция систем
- Новые таблицы БД **не трогают** существующие `Course`, `Stream`, `Lesson`
- Новые роуты `/student/learn/*` **не конфликтуют** с `/student/courses/*`
- Отдельные API endpoints `/api/learning/*` и `/api/library/*`

### 2. Постепенное внедрение
- Каждая стадия — **независимый модуль**
- Можно остановиться на любой стадии
- Откат не ломает существующий функционал

### 3. Совместимость
- Service Worker работает **параллельно** с Socket.io
- Push-уведомления **дополняют** существующие уведомления
- Библиотека **расширяет**, а не заменяет материалы курсов

## 🚀 Порядок реализации

**Результат:** Полноценная платформа с самообучением
