# Настройка Zoho Mail для fatiha.ru

## Шаг 1: Регистрация в Zoho Mail

1. Откройте: https://www.zoho.com/mail/zohomail-pricing.html
2. Нажмите **"SIGN UP NOW"** под планом **Forever Free**
3. Заполните форму:
   - Business Email: введите любой временный email для регистрации
   - Password: придумайте пароль
   - Company Name: Fatiha.ru
4. Подтвердите email

## Шаг 2: Добавление домена fatiha.ru

1. После входа нажмите **"Add Domain"**
2. Введите: `fatiha.ru`
3. Выберите: **"I have a domain and I will update the MX records"**
4. Нажмите **"Add Domain"**

## Шаг 3: DNS записи для REG.RU

Zoho покажет DNS записи. Вам нужно добавить их в панели REG.RU:

### 3.1 Зайдите в REG.RU
1. Откройте: https://www.reg.ru/user/account/
2. Найдите домен **fatiha.ru**
3. Перейдите в **"Управление DNS"** или **"Редактор зон"**

### 3.2 Добавьте MX записи (для получения почты)

**Важно:** Сначала удалите старые MX записи если они есть!

Добавьте 3 новые MX записи:

```
Тип: MX
Имя: @ (или оставьте пустым)
Значение: mx.zoho.com.
Приоритет: 10
TTL: 3600

Тип: MX
Имя: @ (или оставьте пустым)
Значение: mx2.zoho.com.
Приоритет: 20
TTL: 3600

Тип: MX
Имя: @ (или оставьте пустым)
Значение: mx3.zoho.com.
Приоритет: 50
TTL: 3600
```

### 3.3 Добавьте SPF запись (защита от спама)

```
Тип: TXT
Имя: @ (или оставьте пустым)
Значение: v=spf1 include:zoho.com ~all
TTL: 3600
```

### 3.4 Добавьте DKIM запись (подпись писем)

Zoho покажет DKIM запись в формате:

```
Тип: TXT
Имя: zmail._domainkey
Значение: v=DKIM1; k=rsa; p=MIGfMA0GCSqGSIb3DQEBAQUAA... (длинная строка)
TTL: 3600
```

**Важно:** Скопируйте точное значение из панели Zoho!

### 3.5 Добавьте DMARC запись (политика безопасности)

```
Тип: TXT
Имя: _dmarc
Значение: v=DMARC1; p=none; rua=mailto:admin@fatiha.ru
TTL: 3600
```

## Шаг 4: Проверка DNS в Zoho

1. Вернитесь в панель Zoho Mail
2. Нажмите **"Verify Domain"** или **"Check DNS"**
3. Zoho проверит записи (может занять от 5 минут до 24 часов)
4. Когда все записи зелёные — домен подтверждён ✅

## Шаг 5: Создание почтовых ящиков

После подтверждения домена:

1. Перейдите в **"Users"** → **"Add User"**
2. Создайте первый ящик:
   - Email: `info`
   - Display Name: `Fatiha.ru Support`
   - Password: придумайте надёжный пароль
3. Создайте второй ящик:
   - Email: `admin`
   - Display Name: `Администрация Fatiha.ru`
   - Password: придумайте надёжный пароль

## Шаг 6: SMTP настройки для кода

После создания ящиков добавьте в `.env`:

```env
SMTP_HOST=smtp.zoho.com
SMTP_PORT=465
SMTP_USER=info@fatiha.ru
SMTP_PASS=пароль-от-ящика-info
SMTP_FROM=info@fatiha.ru
SMTP_FROM_NAME=Fatiha.ru
```

Или настройте через админку: `/admin/settings` → Email

## Шаг 7: Проверка отправки

1. Перезапустите сервер: `npm run dev`
2. Зарегистрируйте тестового пользователя
3. Проверьте что письмо пришло

- Пароль: ваш пароль

## Troubleshooting

**DNS не проверяется:**
- Подождите 1-2 часа (DNS обновляется не мгновенно)
- Проверьте что записи добавлены правильно
- Убедитесь что удалили старые MX записи

**Письма не отправляются:**
- Проверьте логин/пароль в `.env`
- Убедитесь что используете порт 465
- Проверьте что домен подтверждён в Zoho

**Письма в спаме:**
- Подождите несколько дней (репутация IP прогревается)
- Убедитесь что добавлены SPF, DKIM, DMARC записи
