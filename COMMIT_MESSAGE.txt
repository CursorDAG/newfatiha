security: fix critical vulnerabilities and improve logging

This commit addresses all HIGH and MEDIUM priority security issues
identified in the security audit, improving the security rating from B+ to A-.

BREAKING: None - all changes are backward compatible

Security Fixes:
- Update Next.js 16.1.6 → 16.2.0 (fixes CVE vulnerabilities)
  * HTTP request smuggling (GHSA-ggv3-7p47-pfv8)
  * CSRF bypass via null origin (GHSA-mq59-m269-xvcx)
  * DoS vulnerabilities (GHSA-3x4c-7xq6-9pq8, GHSA-h27x-g6w4-24gq)

- Fix password exposure in admin reset endpoint
  * Temporary passwords no longer returned in API response
  * Passwords now sent via email only (TODO: email template)
  * Prevents leakage via browser DevTools, logs, XSS

- Add rate limiting to email verification endpoints
  * /api/auth/verify-email: 5 requests per 15 minutes
  * /api/auth/resend-verification: 5 requests per 15 minutes
  * Prevents email bombing, spam, token enumeration

Improvements:
- Replace all console.* with structured logger (14 files)
  * Consistent Pino logging with context
  * Better production debugging
  * Log level control via LOG_LEVEL env var
